4. LOCAL OFFLINE EXECUTION INSTRUCTIONS
================================================================================
To run the prototype locally from the submission folder without internet:
1. Open a terminal or command prompt in the prototype directory:
   cd "Assignment-4/prototype"
2. Start the local zero-cache HTTP server:
   python serve.py 8081
3. Open your browser (Google Chrome, Microsoft Edge, or Mozilla Firefox) and navigate to:
   http://localhost:8081
